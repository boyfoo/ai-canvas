# 提供商生成参数扩展

## 职责与入口

连接信息在 `src/lib/model-service-presets.ts` 注册。生成契约在 `src/lib/providers/generation-providers.ts` 注册，由显式提供商 ID 选择；不能根据域名、协议相同或模型名字相同，将一家提供商的扩展套给另一家。

`ProviderGenerationDefinition` 的两个入口：

- `capabilities(base, model, family)`：返回该提供商当前模型的权威能力。输入的 `base` 是本次新建的能力对象，可以修改；不要修改配置中保存的对象。未注册此入口的提供商沿用现有能力来源。
- `parameters`：实现 `ProviderGenerationParameters`，集中声明扩展字段、联动和校验。只注册当前生成执行通道已经实现的参数。连接能访问不等于完整生成链路已经实现。

接口定义和字段备注在 `src/lib/generation-parameter-types.ts`。当前方舟实现分别位于 `ark-video-capabilities.ts`、`ark-video-parameters.ts`，可作为实际范例。

## 同一份声明的使用流程

1. 设置页通过 `constrainedGenerationFields` 和 `providerGenerationFields` 取得通用及扩展参数。保存通用默认值到 `generationDefaults`，服务商原始参数到 `defaultOptions`。
2. 新节点或切换模型时，`generationModelMetadata` 建立当前模型的参数快照。已有节点不会因为后来更改模型默认值而变化。
3. 画布通过 `configuredGenerationParameters` 读取节点快照，传入当前操作和参考素材信息。通用视频控件通过 `videoGenerationSettings` 应用约束；图片、视频和音频弹层均接入同一个扩展字段渲染器。没有扩展字段就不显示入口。
4. 修改扩展字段使用 `patchProviderParameter`；设置页使用 `applicableProviderParameters`。两者都会根据新值重新计算条件，清除不再适用的值。UI 不写 `if (provider_id === ...)` 或服务商参数名单。
5. 提交前调用 `providerRequestParameters`，只投影当前声明的有效字段、应用固定值并校验，再合入当前模式的 `requestOptions`。未声明或当前场景隐藏的配置键不发送，用户配置不能覆盖模式派生的请求参数。请求适配器负责文本、素材、认证和任务生命周期，不再维护另一份扩展参数白名单。

画布继续使用既有参数弹层、选项按钮、开关和输入样式。新增字段放在原弹层的「更多参数」折叠区，不将设置页的通用／扩展分组或表单布局套到画布。

## 接口约定

`fields(context)` 返回当前模型声明的字段，必须是无副作用的纯计算。`context` 包含：

- `profile`：当前模型配置，包括协议和提供商模型系列。
- `values`：当前扩展参数值，键名使用服务商原始 `snake_case`。
- `generation`：通用参数值，使用应用内配置键，如 `videoSeconds`、`vquality`。
- `operation`：当前画布操作。设置模型默认值时不传，不能将其当成文生视频。
- `references`：实际参考素材数量，以及提交阶段已知的视频时长。界面阶段可能尚无素材时长，不得发网络请求补齐。

字段的几种状态必须区分：

| 声明           | 含义                       | 提交处理                                   |
| -------------- | -------------------------- | ------------------------------------------ |
| 不返回该字段   | 此模型不支持               | 不投影到请求                               |
| `hidden: true` | 模型支持，但当前场景不适用 | 不展示、不发送旧值                         |
| `recommended`  | 未明确选择时的显示建议     | 不自动把建议写入请求，服务端使用其默认行为 |
| `forcedValue`  | 当前场景强制的有效值       | 设置页、画布和请求使用同一个固定值         |
| `disabled`     | 禁止手动操作的原因         | 配合固定值展示；没有固定值却传值时拒绝     |

`min`、`max`、`step`、`maxLength` 用于控件及提交校验。数值步长以 `min` 为起点校验，不能只验证整数。`specialValues` 表示范围外的合法特殊值，例如 `-1` 自动时长；它不是从最小值到最大值的一段连续范围。

布尔字段可用 `forces` 固定通用参数；更复杂的通用参数联动用 `constrainCommon(fields, context)`，返回修改后的字段列表。跨字段限制用 `validate(context)` 返回中文错误信息。`read`／`write` 用于控件值与原始 API 值之间的转换，如联网开关与 `tools` 数组；`summary` 可提供画布摘要，避免画布认识具体服务商字段名。

不要在这些函数中修改持久化配置、读取密钥、上传文件或请求接口。参数固定或隐藏只决定本次使用的有效值，不在读取时改写旧节点；用户修改字段后再保存快照。请求始终按当前声明投影，不解释旧配置键、不迁移、不用旧值推断新的操作意图。

## 当前火山方舟视频版规则

依据[官方创建视频任务文档](https://console.volcengine.com/ark/region:cn-beijing/docs/create-video-generation-task-api)，仅应用于 `ark-video`：

| 参数                               | Seedance 2.5 | Seedance 2.0 系列 | Seedance 1.0 Pro / Fast  |
| ---------------------------------- | ------------ | ----------------- | ------------------------ |
| 比例、分辨率、秒数、水印           | 按模型能力   | 按模型能力        | 按模型能力               |
| 自动时长 `duration=-1`、声音       | 支持         | 支持              | 隐藏                     |
| 尾帧、回调、有效期、安全标识       | 支持         | 支持              | 支持                     |
| 样片、输出格式                     | 支持         | 隐藏              | 隐藏                     |
| 联网搜索、任务优先级               | 支持         | 支持              | 隐藏                     |
| 帧数、随机种子、固定镜头、服务等级 | 隐藏         | 隐藏              | 支持；固定镜头仅纯文字输入 |

- 帧数支持 29、33…289；填写帧数后隐藏秒数并省略请求中的 `duration`，清空帧数后恢复秒数。
- 样片固定 480p。转正式是任务详情的独立操作，复用成功样片，只投影该操作允许的输出和任务控制参数，不再次发送样片开关或参考生成参数。
- 2.5 首帧／首尾帧随首图比例；编辑随原视频比例和时长；延长随原视频比例。生成方式只在当前节点选择，`omni_reference_task_type` 由模式内部映射，设置页和参数弹层均不再提供第二个任务类型选项。删除前端自动模式及按素材推断模式的逻辑；所有系列固定默认参考生成，2.5 菜单首项为「自动判断」，其余系列首项为参考生成，添加素材不会改变所选模式。纯文字与 2.5 纯音频输入均合并进参考生成，不再单列文生视频或音频生视频。1.0 的参考生成仅接收文字，图片继续使用首帧／首尾帧模式。
- 编辑的参考视频需为 4–30 秒。URL／素材 ID 的真实信息无法在浏览器读取时，仍由服务商检查；不伪造媒体信息。
- `callback_url` 是方舟向外部服务发送 POST 通知的地址，不是当前页面地址。本项目继续轮询任务，不需要增加中转后端。
- 预置模型 ID 对应的系列固定，自定义 Model ID／Endpoint ID 必须选择实际系列。保存和提交拒绝错配；不自动切换模型。

## 生成模式契约

模式和数值参数统一在提供商层管理。`ProviderGenerationParameters.operations(context)` 声明该模型支持的模式；`defaultOperation(context)` 声明该型号固定的初始模式，不根据素材数量猜测意图。`generation-operations.ts` 负责在设置页、画布、兼容性检查和最终提交中使用同一份声明。显式模式缺少素材时返回原因，不能自动切换；已移除的模式不设兼容别名，需要重新选择有效模式。

`GenerationOperationDefinition` 声明模式名称、帮助、素材角色（`none`／`frames`／`all`）、首尾帧数量、原始请求参数映射和通用参数固定值。`inputIssue` 只表示素材还未就绪：模式仍可选，节点提示补齐素材，提交前统一校验；模型不支持的模式直接不声明。`requestOptions` 由提交投影自动合入，不保存为模型默认值或用户参数，不需要重复编辑。协议通过提示词表达任务意图时可声明 `promptPrefix`，请求适配器将其作为简短任务指令放在用户原提示词之前，不改写保存的用户文字。

普通视频节点在模型选择器后面紧接模式选择，与模型处于同一工具栏，参数弹层不再重复显示模式入口；生成配置节点复用相同的 Select 组件；设置页「能力说明」显示支持模式。模型和模式按完整名称排版并居中，不再共享固定的限宽；工具栏空间不足时换行，长名称允许换行。模式菜单每项直接显示「名称＋用途／素材要求」，缺素材时仍允许先选择；当前模式的素材问题直接在节点内提示。颜色和基础控件沿用现有实现。切换至参考、编辑或延长时清除不再适用的首尾帧选择；帧模式按指定首帧和尾帧提交，不依赖数组碰巧的顺序。1.0 Fast 隐藏尾帧；参考、编辑、延长使用节点已有素材栏，不重复显示另一份素材汇总。比例、时长等仍使用原参数弹层，固定比例的摘要直接显示跟随对象。

首尾帧模式直接展开图片位，空素材时也可添加，不再藏在「参数」折叠区。`canvas-video-frame-slots.tsx` 复用现有 `AssetLibraryPickerModal`、`CachedResourceImage` 和主题，可选画布／素材库图片、上传本地图片、拖入图片、更换、清空及交换角色。尾帧可选，仅支持首帧的型号只显示一个图片位。普通节点的帧图片不在通用素材栏重复展示，额外的图片／视频／音频仍可见，便于处理不符合模式的素材。

`video-frame-selection.ts` 是图片位和请求适配共用的轻量角色顺序规则；`canvas-video-frames.ts` 管理角色与连线的一次性更新。替换和清空只移除当前节点不再使用的引用，保留源图片节点及其他节点的引用；同一张图片可同时用于首尾帧。新导入沿用图片存储及素材节点构建，异步回写受画布生命周期、目标模型和模式保护。连线检查复用文本引用现有的锁定／循环检查，不在组件里直接修改画布文档。

| 模式           | 2.5  | 2.0 系列         | 1.0 Pro | 1.0 Pro Fast |
| -------------- | ---- | ---------------- | ------- | ------------ |
| 自动判断       | 支持 | 隐藏             | 隐藏    | 隐藏         |
| 参考生成仅输入文字 | 支持 | 支持          | 支持    | 支持         |
| 首帧生视频     | 支持 | 支持             | 支持    | 支持         |
| 首尾帧生视频   | 支持 | 支持             | 支持    | 隐藏         |
| 参考生成使用媒体素材 | 支持 | 支持，不可仅音频 | 不支持 | 不支持    |
| 视频编辑       | 支持 | 支持             | 隐藏    | 隐藏         |
| 视频延长       | 支持 | 支持             | 隐藏    | 隐藏         |
| 参考生成仅输入音频 | 支持 | 不支持        | 不支持  | 不支持       |

2.5 的参考生成有媒体素材时映射 `omni_reference_task_type=reference`；只有文字时只发送文本内容，不携带这个全模态字段。编辑、延长分别映射 `edit/extend`，都调用同一个创建任务接口。编辑固定原视频比例与时长，延长固定原视频比例。2.0 没有该任务引导字段，其编辑、延长通过参考视频及模式任务指令表达，不能发送 2.5 专属字段；其时长与比例按 2.0 文档规则设置。

2.5 新增显式 `omni_auto` 模式「自动判断」，发送 `omni_reference_task_type=auto`，由火山服务端根据素材和提示词判断参考生成、编辑或延长。它使用全模态素材角色，不按图片数量推断首尾帧，不添加编辑／延长的提示词前缀，也不恢复已删除的前端自动模式。含参考视频时，提供商将比例固定为 `adaptive`、时长固定为 `-1`，兼容服务端判为编辑时的限制；控件与摘要显示「模型自动适配／模型自动决定」，不承诺跟随原片。没有参考视频时仍按参考生成能力设置比例和时长。官方仍会校验素材和任务语义，例如编辑视频需为 4–30 秒。「自动判断」位于菜单第一项，其余四项相对顺序与默认参考生成不变，其他系列不声明此模式。

`VideoCapabilityConfig.audioOnlyInput` 由提供商声明参考生成是否允许纯音频输入，不要求界面单列音频生成模式。输入提交校验同时支持该能力与其他提供商已有的独立音频模式，删除重复菜单项不会误禁用 2.5 的纯音频能力。

元素替换、风格修改等作为「视频编辑」中的提示词目标，不伪造独立接口或无依据的新模式。样片继续使用既有开关，转正式保留在已完成样片的任务详情中。

## 视频结果与尾帧持久化

方舟查询适配器根据官方返回的 `output_format` 生成结果 MIME：`mov` 对应 `video/quicktime`，其余支持的型号使用 `video/mp4`。浏览器任务记录、下载文件 Blob、视频素材及画布节点共用此格式；下载地址的通用二进制响应头不能覆盖模型的实际容器格式，不执行转码。

开启 `return_last_frame` 后，官方 `last_frame_url` 映射为通用结果中的 `video.lastFrame`。浏览器取回结果时，复用图片存储及 `addGenerationAsset` 保存独立的「方舟视频尾帧」图片素材，现有素材库与首尾帧选择器可直接使用。尾帧使用固定的 `materialize:<task_id>:last-frame` 文件／素材标识，失败重试复用同一份文件与素材；视频和尾帧均保存后才将任务置为 READY。视频保留主输出索引 0，尾帧属于附属素材，通过 `lastFrame.assetId` 及视频素材的 `metadata.lastFrameAssetId` 关联，不混入批量视频输出。

已保存的尾帧不随再次绑定视频而重新创建；用户可独立管理该图片。参考视频的最低总像素按官方契约使用 `407696`（614×664），由提供商能力统一用于画布与提交校验。

## 新增提供商时

1. 先核实官方模型能力、字段取值、任务场景与实际执行通道。
2. 在 `src/lib/providers/` 编写该提供商的能力和参数实现，注册到 `generation-providers.ts`，并在连接定义中声明提供商身份及执行方式。
3. 请求适配器消费 `providerRequestParameters` 的结果。若任务还有专门的上下文约束，补充类型化的上下文及提供商规则，保持界面无业务判断。
4. 保留现有组件及样式；只有新类型无法由已有字段控件表达时，才增加通用控件类型，不能为每家提供商复制设置面板。
5. 按项目要求不编写、不运行测试代码。使用 TypeScript、ESLint、生产构建检查，并在浏览器可用时核验界面；真实生成需使用有效账号验证，不把构建成功写成接口调用成功。
