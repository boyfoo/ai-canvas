# Canvas

从 BeefTV 提取的独立画布前端工程，基于 React 19、TypeScript、Vite、Ant Design 和 Zustand。保留原画布渲染与交互实现，适合在此基础上继续开发。

上游固定为 `glanderness/BeefTV` 的 `b3b6e2e380cb13cead3b7eb0d9c479a0f7125fad`。许可与版权信息保留在 `LICENSE`、`NOTICE` 和 `THIRD_PARTY_NOTICES.md`。

## 保留范围

画布、全部内置节点、连线、分组、快捷键、撤销重做、导入导出、素材工具、生成参数、模型渠道、助手与技能、工作流、分镜、导演工作台、时间线、字幕、转写、媒体转换和它们的资源均保留。画布链接使用的素材、技能、扩展与项目画风等支持页面继续提供路由。

移出了桌面更新、Wails 绑定、系统目录迁移、全站产品侧栏与搜索、独立首页／创作／Agents／实验页面。没有复制 Go 后端、Node 助手宿主或 Python 处理工具。

## 运行

需要 Bun 1.3.11 或更新的兼容版本。**基础画布无需后端即可运行**：项目、节点、连线和素材保存在当前浏览器的 IndexedDB，支持编辑、刷新恢复与导入导出。

```sh
bun install --frozen-lockfile
bun run dev
```

默认地址为 `http://127.0.0.1:3000/canvas`。开发时启动的是 Vite 静态资源服务；最终构建产物是 `dist/` 静态文件，部署时让前端路由回退到 `index.html` 即可。基础画布不需要配置 `/api` 代理。

模型渠道和密钥保存在当前浏览器的本地存储中，模型目录和底层模型传输直接请求配置的服务商地址，不经过工作区后端。服务商必须支持浏览器 CORS。原来的生成任务队列、助手宿主、插件运行及深度处理仍依赖服务接口，尚未全部改成浏览器执行；基础画布启动与保存不会等待这些服务。

顶部导航统一使用「设置」入口，页面内分为「连接管理」「默认模型」「存储设置」，参考素材存储与深度服务位于「存储设置」。「默认模型」使用独立页面 `/settings?section=models`，负责选择应用默认使用哪个模型，不再显示在连接编辑区底部。「连接管理」统一采用左侧连接列表、右侧编辑区域，每个连接分为「连接信息」「模型管理」「素材传输」，新增与编辑均通过「保存／取消」提交草稿。模型详情分为「能力说明」「参数默认值」「接入设置」；参数以「通用」「扩展」标识分区，扩展注明提供商或模型系列来源。参数选项按已声明的模型能力与执行通道显示，不支持或未实现的选项隐藏。参数默认值只用于新建节点，已有节点保存自己的参数快照。图片自定义尺寸、Seedream 参数和音频设置复用已有控件；通用／扩展分组仅出现在设置页，画布生成操作区保持原有面板、按钮和弹层样式。

可在连接编辑区底部「保存」旁点击「检查连接」，无需先保存。连接参数用途通过字段旁的问号提示查看。火山方舟默认用 GET 读取视频任务列表，不创建生成任务；也可更换同一服务下的请求地址、方法和 JSON 请求体。检查会显示可读取的 HTTP 状态和响应摘要；浏览器无法读取响应时，需结合 Console / Network 区分 CORS、网络和 TLS 问题。POST 会真实调用指定接口，生成请求可能产生费用。连接检查、目录读取、生成验证分别展示，某个地址可访问不代表模型已开通。

新增一级服务商「火山方舟(视频版)」，与 OpenAI、Google Gemini、原「火山方舟」并列。选择后填写 API Key，点击「选择预置模型」勾选 Seedance 视频模型；也可填写 Model ID / Endpoint ID 并明确选择模型系列。预置列表只提供配置选项，实际可用性由账号开通情况决定。该提供商不请求 `/models`，原有提供商继续使用原来的模型读取流程。视频创建、查询、取消及画布结果保存由浏览器执行，不需要业务后端中转。其他服务商的完整生成链路仍按原实现执行。

在连接的「素材传输」中，只显示已启用模型支持的素材类型，可以分别选择其传输方式，统一应用于此连接：火山方舟 Files API、已有对象存储、手动 HTTPS 链接或直接传入。方舟视频版的自动方式为图片和音频直接传入、本地视频上传 Files API。Files 地址由当前服务地址拼接 `/files`，使用该连接的 API Key；它是可选云端存储方式，原对象存储配置继续独立使用。原对象存储仍需配置对应宿主服务，未配置时可使用现有链接填写流程。上传 Files 后查询真实 `download_url` 再提交视频任务，不把 File ID 当作 asset ID。Files 临时文件和链接会过期，原素材及成功取回的生成视频保留在浏览器 IndexedDB。

任务记录使用 `app_state` 中 `infinite-canvas:provider-tasks:user:<scope>:browser-task-*` 保存，不保存每任务密钥；刷新后按上游任务 ID 继续查询。提交结果不确定时不会自动重发，可在任务详情关联方舟控制台中的原任务 ID。关闭页面会暂停浏览器轮询，恢复页面后继续观察。生成及文件上传分别受服务商 CORS、账号权限和计费规则约束。

请求参数依据[视频生成 API](https://console.volcengine.com/ark/region:cn-beijing/docs/create-video-generation-task-api)、[上传文件](https://docs.volcengine.com/docs/ark/upload-files-api?lang=zh)及[文件详情](https://docs.volcengine.com/docs/ark/search-files-api?lang=zh)实现。提供商层统一声明模型能力、参数显隐、固定值、联动及校验，设置页、画布和请求投影共用定义。画布继续使用原有生成控件，支持的扩展放在原弹层「更多参数」内；图片、视频和音频共用扩展入口。火山视频版补齐智能时长、帧数和回调，按系列及素材场景显示。生成方式只在当前节点选择，删除前端自动选择，纯音频输入并入参考生成；任务类型由提供商内部映射，不需要再去设置页指定。首尾帧直接显示两个图片位，复用素材选择器与图片存储，支持上传、更换、清空和交换；仅支持首帧的型号只显示首帧。缺素材时允许先选模式，节点直接提示补齐。请求只投影当前允许的参数。扩展方式与代码职责见[提供商生成参数说明](docs/provider-generation-parameters.md)。Seedance 2.5 的样片固定提交 480p；「样片转正式」移到已完成样片的任务详情，固定关联原任务并防止重复创建，不再把任务 ID 保存成模型默认值。

浏览器可选择和拖入本地文件、下载导出文件，并执行已有的浏览器媒体处理；运行 Python、本机命令及不受限制的磁盘目录操作需要另行接入本地工具服务。静态站点地址（协议、主机、端口）不同会使用不同的浏览器存储，迁移站点时应先导出项目。

```sh
bun run typecheck
bun run test
bun run build
bun run start
```

浏览器冒烟需要 Node.js 20+ 和已安装的 Google Chrome：先构建，再运行 `bun run test:browser`。测试仅提供静态构建文件，验证无后端启动、新建、节点改名与拖动、素材保存、刷新恢复、ZIP 导出，以及独立 CORS 模型服务的直连与配置保存；不调用真实模型。

构建默认包含全部高级媒体资源，无精简构建开关。`bun run start` 预览静态产物。只有使用可选工具服务时才需要 `VITE_CANVAS_BACKEND_URL`，开发代理地址用 `VITE_API_PROXY_TARGET` 配置（支持 `.env.local`）。

锁文件保留上游依赖版本与完整性校验值，将镜像下载地址归一到 npm 官方源；Vidstack 补丁继续通过 Bun 应用。

火山视频版统一使用「参考生成」接收纯文字或模型支持的参考素材，并将它放在模式菜单第一项；不再单列文生视频或音频生视频。Seedance 2.x 的其余模式为首帧／首尾帧、视频编辑和视频延长；1.0 按实际能力仅保留参考生成（纯文字）和首帧／首尾帧。

## 二次开发入口

- `src/pages/canvas`：画布页面、交互与生成流程。
- `src/components/canvas`、`src/lib/canvas`、`src/stores/canvas`：组件、算法与状态。
- `src/router.tsx`、`src/layouts/canvas-layout.tsx`：独立入口及支持页面。
- `src/services/api`：现有业务 HTTP、资源和事件流客户端。
- `src/services/canvas-host.ts`：原生桥接改造后的宿主服务合同。
- `src/lib/canvas-host-config.ts`：API 地址与资源存储策略。
- `docs/extraction-manifest.json`：移出文件记录。

宿主可以在 `main.tsx` 执行前注入 `window.__CANVAS_CONFIG__` 与 `window.__CANVAS_SERVICES__`，也可以直接实现默认 HTTP 合同。对象存储设置、参考素材上传和深度状态这 **6 个 `/api/canvas-host/*` 接口是本次定义的适配合同，上游 Go 服务并未自动新增这些接口**。接入方法见 [后端与宿主合同](docs/backend-contract.md)。

“本地工作区”表示浏览器内的单工作区，不等于桌面运行环境。默认使用浏览器素材存储；需要接入资源服务时，可通过显式资源存储配置切换。

测试和验证范围见 [抽离说明](docs/extraction.md)。
